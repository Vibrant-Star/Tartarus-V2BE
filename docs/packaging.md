# Portable Windows release

Run `scripts/Build-Release.ps1` from a Windows development checkout with Rust/Cargo and the x86_64-pc-windows-msvc toolchain installed. The builder compiles the locked dependencies, obtains Cargo's dependency metadata, and creates a uniquely named folder and ZIP under `dist/`. Existing outputs are never overwritten. The ZIP is a preview artifact, not a signed installer or a claim that every hardware acceptance item is complete.

`scripts/Prepare-PackageInputs.ps1` fetches only missing packaging inputs from official upstream locations and checks pinned SHA256 values. It can be run separately while online, then packaging can use cached inputs offline if Cargo dependencies/toolchain are also available. A changed upstream archive is rejected for manual review. No downloaded binary is executed by preparation or packaging. Review the pinned hashes when intentionally updating Interception.

The portable bundle contains the release executable, a replaceable x64 Interception DLL, the matching upstream command-line driver installer, fresh native/default JSON settings, documentation, dependency notices, GPL/LGPL texts, Inter font license, the exact upstream tag source archive. Our project source is emitted as a separate adjacent source ZIP. Library source is provided locally rather than relying on a website link. Rust dependency notices include Unicode and other additional notices found in the cached crate distributions. Local profiles, source_import backups, capture logs, device paths, research snapshots and the development vendor tree are not copied. The upstream binary archive is verified before selected assets are extracted.

Interception's README distinguishes LGPL library/source from separately distributed driver/installer binaries and grants non-commercial binary distribution permission for use through the library API. Its standard LGPL text and stated non-commercial/commercial split are preserved rather than simplified into an MIT claim. See the bundled upstream README and THIRD-PARTY.md. This project does not redistribute a commercial silent-installer library or claim to provide the unavailable public driver/installer source.

Driver helpers use the preserved installer, require an administrator context and a typed INSTALL/UNINSTALL confirmation, validate the installer's pinned hash, record state and never reboot automatically. The package build must not execute Install or Uninstall as a test. Only read-only checks, script parsing and user-space smoke tests are appropriate without separate driver approval.

The app is removed by disabling its autostart, stopping/exiting, backing up data and deleting its portable folder. Interception removal is explicitly separate because it may be shared. A confirmed fallback autostart helper displays the existing registered command before removing the named entry; it does not stop apps or remove drivers. START-HERE.md and RECOVERY.md explain removal and input-failure recovery.

`manifest.sha256` covers packaged files; the adjacent ZIP SHA256 covers the finished archive. These are integrity checks, not publisher authentication. The builder deliberately does not embed a DLL hash requirement in the runtime: API-compatible modified libraries remain replaceable. Initial settings disable autostart, automatic remapping and RGB management, and show the tray icon.
